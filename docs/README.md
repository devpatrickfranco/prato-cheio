# Documentação do Prato Cheio

Cada documento tem um único papel. Quando um fato já tem dono, os outros arquivos apenas apontam para ele.

| Papel | Onde está | O que responde |
|---|---|---|
| Regras e visão geral | [README.md](../README.md) | Como rodar, estrutura de pastas, arquitetura e convenções de Git |
| Escopo e pendências | [escopo.md](escopo.md) | O que está dentro e fora do projeto e o que falta fazer |
| Decisões | [adr/](adr/) | Por que cada decisão difícil de reverter foi tomada (ADRs numerados) |
| Histórico de correções | [correcoes-auditoria.md](correcoes-auditoria.md) | O que a auditoria encontrou e como foi corrigido |
| Material acadêmico | [modelo-documento-2a-entrega.pdf](modelo-documento-2a-entrega.pdf), [screenshots-prototipo/](screenshots-prototipo/) | Entrega da disciplina, protótipo e diagrama MER/DER |

Ao mudar a estrutura de pastas, atualize a árvore do README. Ao tomar uma decisão difícil de reverter, crie o próximo ADR em `adr/`.
